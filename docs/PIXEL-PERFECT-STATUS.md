## Shared reference (Session 1)

- **Container:** `.page-width` / `.custom-container` → `max-width: var(--page-max)` (1512), padding `var(--page-gutter-mobile)` 20 → `var(--page-gutter)` 55 at 990+. Deeper Figma insets go inside it.
- **Type:** Inter 400/500/700/900 + Plus Jakarta Sans 700 only (Google Fonts). Line-height "normal" = `leading-figma` (Inter 1.21, Jakarta 1.26). Tracking 4% = `tracking-heading`, 6% = `tracking-heading-wide`.
- **Buttons** — always `.ctm-button` + one variant. Base: px 28, py 10, 2px border, radius 80, Inter Medium 16 uppercase, gap 10, 20px icon.
  - `.btn-outline-gradient` white fill, gradient border (44 / 43)
  - `.btn-dark-gradient` black fill, gradient border
  - `.btn-glass-gradient` 48% black fill, gradient ring
  - `.btn-white` solid white
  - `.btn-black` solid black, no border (39) — Figma 23:9494
  - `.btn-gradient` gradient fill, no border (39) — Figma 23:7864
- **Colors:** `black white cream rocket-red orange light-orange magenta electric-blue deep-purple ink`, `bg-gradient-brand`, `bg-gradient-cream`.
